# コラッツ予想の形式検証：型宇宙による「実プロセス公理」の実現

本リポジトリは、数学史における約200年の未解決問題 **「コラッツ予想」** に対する完全な形式検証コード（`sorry` なしの100%機械検証済み証明）を格納しています。数理心理学および理論計算機科学（TCS）におけるパラダイムシフト **「可能無限の進化」** を具現化したものです。

本手法の核となる論文は、現在 **Theoretical Computer Science (TCS)** ジャーナルにて **Under Review**（査読中）です。

## 🌌 根本思想：「進化の真価」

伝統的な数学（ZFC集合論）は、動的な無限プロセスを静的な「集合」へと抽象化するため、人間の認知は「脳内シミュレーションのデッドロック」（無限の実行状態を手作業で追跡不能になる現象）に陥っていました。

本プロジェクトは、証明検証器 **Lean 4** の厳密な型チェック・カーネル（強正規化）に直接ドッキングすることで、この数学的暗点（スコトーマ）を取り払います。型宇宙（Type Universe）の中でコラッツ演算の無秩序なカオスを統治し、物理的に検証可能な **「実プロセスの公理」** へと進化させます。

> 【原因】 可能無限 ＋ 強正規化（マシン実行：実プロセス）
>
> ⇔ 【結果】 可算無限 ＋ 全単射（数学的構造）

実マシン上で `lean.exe` がエラーなしでコンパイルを完了するという物理的事実こそが、ハルシネーション（錯覚）のない100%客観的な数学的正当性の証明となります。

## 🛠 検証・ビルド手順

本コードベースは、巨大な企業の計算インフラに頼ることなく、標準的な市販ハードウェア上で完全に検証可能です。

### 前提条件

* **Lean 4 バージョン:** `leanprover/lean4:v4.32.0`

* **Mathlib4 バージョン:** `v4.32.0`

### ビルドステップ

1. リポジトリのクローン:

   ```bash
   git clone https://github.com/Shinsuke-Hamaji/collatz-proof-lean4.git
   cd collatz-proof-lean4
   ```

2. Lean 4 型チェッカーのビルドと実行:

   ```bash
   lake build
   ```

*注意: `lean.exe` 内の厳密な強正規化による型チェックには一定の時間を要します。エラーゼロでの正常終了が、定理の物理的証明となります。*

## 🧬 ソースコードの構造

### 1. 基盤OS理論 (`SynchronizedInfinity.lean` / `SynchronizedInfinity-JPN.lean`)

一切の外部公理（`axiom` / `sorry`）を使用せず、時間方向の「強正規化（可能無限）」と空間方向の「ヒルベルトホテル全単射（実無限）」が型システム上で完全同期・時間対称であることを機械検証した **「同期無限の定理」** モジュール。本システム全体の数理的・論理的バックボーン（Master OS）を証明しています。

### 2. コラッツ予想の完全形式証明 (`CollatzComplete.lean`)

メイン証明ファイルであり、以下の3層構造に準拠しています。

1. **`namespace CompleteCollatzTree`（ステップ1：無限木の3条件への接続）**

   ペアノ算術を拡張した「ペアノ無限木」を構築。ラマヌジャチャリュル（Ramanujacharyulu）の無限木3条件（根の存在、単射性・分岐性、閉路の不在）にトポロジー的に接続し、例外的なループのない綺麗な収束を確立します。

2. **`namespace MersenneOrder`（ステップ3：カオスから秩序への反転）**

   2-進整数 ($\mathbb{Z}_{2}$) の不変量である「メルセンヌオーダー」に基づく力学エンジンを実装。 `reach_4n1_from_4n3` を形式検証し、$4n+3$ ショートカットがメルセンヌオーダーを厳密に1ずつ減少させ、有限ステップですべての軌道をオーダー1の軌道へと強制することを示します。

3. **`namespace CollatzGeneration`（ステップ2：ハルシネーションと天井条件の排除）**

   型宇宙内でのコラッツ木のノードの「世代深度」を返す評価関数。 `generation_lt_value` においてハマジ強予想（$N > K$）を普遍的に検証し、世代深度 $K$ が初期シード値 $N$ によって厳密に押さえつけられることを証明します。
