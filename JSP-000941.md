## 3. Module Specifications and Proof Components

### 3.1 [Part 1] Infinite Tree Topology Module (`CompleteCollatzTree`)

Defines the topology of the complete inverse map tree constructed from the reverse operations of the standard Collatz map, establishing the 3 conditions of the infinite tree.

* **`CollatzTree : Nat → Type`**:
  * An algebraic data type with four constructors: `root` ($n=1$), `even_step` ($2n$), `odd_step_4n1` ($4n+1$), and `odd_step_4n3` ($4n+3$).
* **`parent`**:
  * A structural function deterministically returning the unique parent (pre-image) of each node.
* **`not_root_has_parent` (Conditions 1 & 2: Complete Elimination of Empty Sets)**:
  * Proves that any node $t$ other than the root ($1$) strictly possesses a unique parent (`parent t ≠ none`).
* **`root_no_parent` (Confirmation of Unique Root)**:
  * Proves that the root ($1$) itself is the sole base point with no parent.

### 3.2 [Part 2] Mersenne Order Module (`MersenneOrder`)

Constructs a monotonic decrement chain of the invariant `mo` (Mersenne Order) in binary $p$-adic space.

* **`mo (n : Nat)`**:
  * An invariant function evaluating the count of trailing consecutive $1$s in the binary representation of natural number $n$.
* **`mo_4n1_eq_one`**:
  * Proves that odds of form $4n+1$ always lie on the absolute boundary wall of $mo = 1$.
* **`mo_4n3_eq_mo_6n5_plus_one`**:
  * Proves that the shortcut operation $(3x+1)/2$ on $4n+3$ odds strictly decrements $mo$ by $1$ (`mo(4n+3) = mo(6n+5) + 1`).
* **`reach_4n1_from_4n3`**:
  * Proves via strong induction that all $4n+3$ odds connect to an orbit with $mo = 1$ ($4n+1$ orbit) within a finite number of shortcut steps.

### 3.3 [Part 3] Hamaji's Conjecture & Generation Module (`CollatzGeneration`)

Proves global finite convergence via an evaluation function derived from the infinite tree topology.

* **`generation {n : Nat} (t : CollatzTree n) : Nat`**:
  * A recursive function calculating the structural depth (generation) from the tree root ($1$) to node $n$.
* **`generation_lt_value` (Hamaji's Conjecture: Structural Proof of Strong Normalization)**:
  * **Core Theorem**: In any infinite Collatz tree, the generation depth is strictly less than the numeric node value itself (`generation t < n`).
  * **Logical Significance**: Regardless of localized numerical fluctuations, the topological depth is strictly bounded by the numerical ceiling $n$. This guarantees globally that trajectories cannot diverge endlessly and must terminate at the root ($1$) in finite steps.

### 3.4 [Part 4] Synchronized Infinity Integration Module (`SynchronizedInfinity`)

Integrates spatial bijection (actual infinity) and strong normalization (potential infinity) under temporal symmetry.

* **`SynchronizedMaster (α β : Type)`**:
  * A master structure where bijection and inverse evaluation satisfy time symmetry (`inv_eval (bijection x) = x`).
