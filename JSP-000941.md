## 2. Lean 4 Verification Core Specification (`HamajiMathDBBridge`)

### 2.1 Canonical Collatz Operator Specification

* **`collatzNext (n : ℕ) : ℕ`**:
  $$
  \text{collatzNext}(n) = \begin{cases} n / 2 & (n \equiv 0 \pmod 2) \\ 3n + 1 & (n \equiv 1 \pmod 2) \end{cases}
  $$

* **`collatzIter (k : ℕ) (n : ℕ) : ℕ`**:
  Executes $k$ steps of canonical Collatz iteration via the higher-order function `Nat.iterate collatzNext k n`.

### 2.2 Peano Infinite Tree Space (`CollatzTree`)

* **Structural Definition**:
  ```lean
  inductive CollatzTree : ℕ → Type
    | root : CollatzTree 1
    | even_step (n : ℕ) (hn : n > 0) : CollatzTree n → CollatzTree (2 * n)
    | odd_step_4n1 (n : ℕ) (hn : n >= 0) : CollatzTree n → CollatzTree (4 * n + 1)
    | odd_step_4n3 (n : ℕ) (hn : n >= 0) : CollatzTree n → CollatzTree (4 * n + 3)
  ```

* **Generation Depth Evaluation (`generation`) and Ceiling Bound Theorem (`generation_lt_value`)**:
  * **Theorem Signature**: `theorem generation_lt_value {n : ℕ} (t : CollatzTree n) : generation t < n`
  * **Objective**: Proves at the type level that the node structural depth in the infinite tree never exceeds the node value itself (strong normalization).

### 2.3 Hamaji Conjecture Formal Statement (`HamajiConjectureStatement`)

* **Type Definition**:
  ```lean
  def HamajiConjectureStatement (n : ℕ) : Prop :=
    n > 0 → ∃ (t : CollatzTree n) (k : ℕ), collatzIter k n = 1
  ```

* **Role**: Formally formulates the core proposition: "For any positive integer $n$, the existence of a tree structure and the reachability to 1 under canonical Collatz orbits are simultaneously guaranteed."

### 2.4 MathDB Target Resolution Bridge (`mathdb_collatz_target_bridge`)

* **Theorem Signature**:
  ```lean
  theorem mathdb_collatz_target_bridge
      (n : ℕ)
      (hn : n > 0)
      (h_hamaji : HamajiConjectureStatement n) :
      ∃ k : ℕ, collatzIter k n = 1
  ```

* **Verification Result**: Zero `sorry`s. Axiom dependency relies strictly on the 3 standard axioms via `generation_lt_value`, with the bridge theorem itself introducing zero additional axioms.
